# shooter

Release の Assets から自分の OS の zip をダウンロードします。

## Windows 10 / 11

1. `shooter-<版>-windows.zip` を右クリックして「すべて展開」を選びます。zip の中からは起動できません。
2. `shooter.exe` をダブルクリックします。フォルダの中のほかのファイルは同じ場所に置いたままにします。
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します (初回だけ)。

## macOS 12 以降

1. `shooter-<版>-macos.zip` を展開し、`shooter.app` を「アプリケーション」へ移します。
2. `shooter.app` を **control キーを押しながらクリック** し、「開く」を選び、もう一度「開く」を押します (初回だけ)。

「開く」が出ないとき (macOS 15 以降): 一度ダブルクリックして閉じ、「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を押します。

「壊れているため開けません」と出るとき: ターミナルで次を実行してから開き直します。

```sh
xattr -dr com.apple.quarantine /Applications/shooter.app
codesign --force --deep --sign - /Applications/shooter.app
```

## オンラインで遊ぶ

メインメニューの「ONLINE - QUICK MATCH」(日本語では「オンライン - クイックマッチ」) を押します。接続が切れたらメニューに戻るので、もう一度押します。

「ONLINE - PARTY」と「ONLINE - JOIN BY CODE」は、オンラインのサービスを使えるときだけメニューに出ます。出ていなければ、この 2 つは使えません。

### コードで入る

参加コードの要る試合には、試合を立てた人から聞いたコードで入ります。

1. メインメニューの「ONLINE - JOIN BY CODE」(「オンライン - コードで入る」) を押します。
2. 「Join code」(「参加コード」) の欄にコードを入れ、「JOIN」(「入る」) を押します。

入れないときは、そのわけが出ます。

- 「No match has that code. Check the code.」(「このコードの試合は見つからなかった。コードを確かめる」): コードを確かめて入れ直します。
- 「That match is full.」(「この試合は満員で入れない」): 空くのを待ちます。
- 「That match runs a different version of the game.」(「この試合とゲームのバージョンが違うので入れない」): 試合を立てた人と同じ版のゲームを使います。

### パーティ

同じパーティの人は、同じ試合に入ると同じチームになります。

1. 1 人がメインメニューの「ONLINE - PARTY」(「オンライン - パーティ」) を開き、「CREATE PARTY」(「パーティを作る」) を押します。
2. 「Invite code」(「招待のコード」) の欄に出たコードを仲間に伝えます。
3. 仲間は「ONLINE - PARTY」を開き、そのコードを入れて「JOIN」(「入る」) を押します。「Members」(「メンバー」) に全員が並べば揃っています。
4. 全員が「BACK」(「戻る」) でメニューに戻り、「ONLINE - JOIN BY CODE」で同じ参加コードを入れます。

クイックマッチでも、パーティの人数分の空きがあるサーバーを探します。ただし仲間についていくのではないので、全員が同じサーバーに入るとは限りません。
パーティを抜けるときは「LEAVE PARTY」(「パーティを出る」) を押します。
